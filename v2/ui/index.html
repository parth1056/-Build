WHAT THIS MEASURES
Developer waiting time, locally.
From workspace image build through validation, artifact build, runtime packaging and exact-image verification. Both methods receive the same local package inputs. Network installation is disabled.
WHAT IT DOESN'T PROVE
No universal speedup.
Not internet download savings, production deployment, cloud cost or energy. Parallel checks use more resources at once. Synthetic document fixtures are disclosed. BuildKit runs in every method.
HOW TO CHALLENGE IT
Inspect the counterexamples.
Try an empty cache, a dependency upgrade, the small workload or an already optimized starting pipeline. Negative results remain visible. A failed check must block packaging.
